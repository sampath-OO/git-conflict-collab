# git-conflict-collab
Demonstration of Git branching, collaborative workflows, and merge conflict resolution

## Module Information

### 1. User Profile Management System
- **Developed by:** Developer A (Feature Branch)
- **Features:** Profile creation, avatar upload, and user role assignment.

### 2. Authentication & Security Gateway
- **Developed by:** Developer B (Main Branch Lead)
- **Features:** OAuth2 login, JWT session management, and rate limiting.

### Collaboration & Conflict Resolution Note
Both features were concurrently developed on separate branches (`main` and `feature/user-profile`). The merge conflict was manually resolved by integrating both modules into a unified project structure.
